# 功能覆盖矩阵

## 当前无数据库模式限制

- 主 API 重启会丢失任务、结果、审计、会话、项目、成员和导入算法注册记录。
- 图片、视频、算法包和模型文件保留在宿主机目录，但主 API 重启后需要重新建立索引。
- Algorithm Manager 会通过 Docker 标签重新发现受管容器。
- 内置算法与默认项目使用确定性 UUID，重启后 ID 稳定。
- 多节点注册、灰度权重和扩缩容策略同样是内存状态，长期运行前应在服务器持久化阶段迁移。

这些限制是当前用户明确选择，不属于功能遗漏；后续只需替换仓储/存储/队列实现，不改变 API 与领域模型。
